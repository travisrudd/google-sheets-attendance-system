# Roadmap

## Future integration

- Merge the attendance check-in system with the coaching schedule application
  so registration, identities, scheduling, and attendance behave as one app.
- Before merging, define a shared person/member identity and decide which system
  is authoritative for contact information.
- Preserve existing attendance tokens or provide a migration path so saved
  attendee links continue to work.

## Possible follow-ups

- Administrator-driven resend or token replacement workflow
- Rotating classroom code or location verification
- Registration CAPTCHA if public-link abuse becomes a problem
- Delivery and registration audit log
- Attendance history visible to each attendee
